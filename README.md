# 🏋️ 1 Week Gym Workout

A simple weekly gym workout plan designed to target all major muscle groups.

## 📅 Weekly Workout Schedule

| Day | Workout Type | Main Exercises | Sets × Reps |
|---|---|---|---|
| Monday | Push A (Chest, Shoulders, Triceps) | Barbell Bench Press, Incline Dumbbell Press, Overhead Dumbbell Press, Triceps Rope Pushdown | 4×8-10, 4×8-10, 3×10-12, 3×12-15 |
| Tuesday | Pull A (Back, Biceps, Rear Delts) | Lat Pulldown, Bent-over Barbell Row, Dumbbell Biceps Curl, Face Pulls | 4×8-10, 3×8-10, 3×10-12, 3×12-15 |
| Wednesday | Legs & Abs | Barbell Squats, Romanian Deadlift, Leg Press, Hanging Leg Raises | 4×8-10, 3×10-12, 3×12-15, 3×15-20 |
| Thursday | Active Rest / Recovery | Light Stretching, Walking, Mobility Work | Rest Day |
| Friday | Push B | Incline Barbell Press, Dumbbell Chest Flyes, Dumbbell Lateral Raises, Skull Crushers | As needed |
| Saturday | Pull B & Deadlift | Conventional Deadlift, Seated Cable Row, Hammer Curls, Reverse Flyes | 3×5, 3×10-12, 3×10-12, 3×12-15 |
| Sunday | Full Rest | Complete Rest & Muscle Recovery | Rest Day |

## 🎯 Goals
- Build strength and muscle.
- Train all major muscle groups.
- Maintain a consistent workout routine.
- Allow proper muscle recovery.
